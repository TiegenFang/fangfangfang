# 文章阅读页双导航

日期：2026-10-10。状态：页面与交互已实现，浏览器验收及项目完整检查已通过；代码审查进行中。

## 目标与范围

改善桌面文章阅读页两侧空间闲置的问题，用导航支持阅读，而不是把正文文字铺满屏幕。主要验收场景为大显示器上的最大化浏览器窗口。

本次范围为文章阅读页，包括独立文章与课程讲义。首页、文章列表、课程详情页、项目与影像页面不在本次改动范围内。

## 用户已确认的决策

- 宽屏讲义页采用左侧课程导航、中间正文、右侧本文目录。
- 讲义页同时提供两种导航；独立文章只提供本文目录，不用其他内容填充课程导航的位置。
- 保留正文阅读宽度，不为容纳三栏而挤压正文。
- 空间不足时先收起课程导航，保留正文与本文目录；继续变窄后收起本文目录。
- 收起的导航通过抽屉面板打开，不推挤正文。
- 讲义页底部改为课程内的“上一讲／下一讲”；独立文章底部保持现有发布时间导航规则。
- 主要桌面验收场景为大显示器最大化窗口，不以分屏体验作为首要布局目标。

## 概念与现有规则

**课程导航**索引同一课程的讲义；**本文目录**索引当前文章的章节。不能用不带限定的“目录”混称二者。课程导航及相邻讲义的定义已记录在根目录 `CONTEXT.md`。

课程导航复用 `src/utils/getCourseLectures.ts` 的既有规则：仅包含可发布讲义，已指定讲次升序，未指定讲次排在之后，相同讲次按发布时间先后排列。“上一讲／下一讲”指此排序中的相邻讲义，而不是全站时间线中的相邻文章。

原有 `src/pages/posts/[...slug]/index.astro` 的底部导航按全站时间线排序（修改时间优先，未修改时使用发布时间）。讲义页已切换到课程顺序；独立文章保留此现有时间线规则，不把邻接集合改为只含独立文章。

## 建议采用的交互默认值

以下为访谈中提出的实施默认值，未逐项要求用户选择；实现时如需改变，应说明与阅读目标的关系。

- 桌面侧栏随正文滚动保持可见；长导航在自身区域滚动，不强迫读者滚回页面顶部。
- 课程导航标识当前讲义；本文目录随阅读位置标识当前章节，默认展示二、三级标题。
- 没有适用章节标题时不显示空本文目录；独立文章不显示空课程导航。
- 抽屉入口在阅读中保持可达，不仅放在文章顶部。
- 选择讲义或章节后关闭抽屉；章节跳转定位正文，课程切换使用正常页面链接。
- 抽屉有明确的关闭按钮，支持 Esc；打开、关闭及选择目标时管理键盘焦点，打开期间不让焦点进入被遮挡的正文。
- 第一讲没有“上一讲”，最后一讲没有“下一讲”；单讲课程不生成虚假的相邻讲义链接。

## 响应式约束

断点按浏览器可用 CSS 宽度确定，不直接使用显示器物理分辨率。具体断点、侧栏宽度与间距在实际页面验证时确定，不在访谈中硬编码。

宽屏优先同时显示两种导航；中等宽度优先保留本文目录；手机宽度两种导航均按需通过抽屉打开。整个过程不得靠缩小正文字号、压缩正文阅读宽度或引入整页横向滚动来维持三栏。

只显示一侧导航或没有导航时，不渲染无意义的占位卡片。留白本身不是必须填满的内容区域。

## 实施边界

- 沿用现有 Astro 页面、课程讲义排序与站内 URL 工具，兼容 GitHub Pages 的 `/fangfangfang` 子路径。
- 不新增内容集合、讲次规则、推荐模块或文章归属字段。
- 不把本次布局扩展为全站首页重构，不改变独立文章底部导航的现有语义。
- 这些布局选择可逆，当前不为其新增 ADR。

## 验收场景

- 大屏最大化窗口阅读长讲义：课程导航、正文、本文目录同时可见；正文保持阅读宽度。
- 滚动长讲义：侧栏持续可用，当前讲义及当前章节标识正确；长课程导航可在自身区域访问全部讲义。
- 从第一讲、中间讲和最后一讲继续阅读：底部前后讲与课程导航顺序一致，不跳出当前课程。
- 阅读独立文章：只有适用的本文目录，底部前后篇行为保持现状。
- 阅读无章节标题的短文：没有空目录卡片或无效的目录按钮。
- 连续缩窄窗口：课程导航先收起，本文目录后收起；正文不被挤压，没有整页横向滚动。
- 在窄屏从正文中段打开抽屉：正文排版不移位；可关闭、可选择目标，键盘焦点与跳转位置正确。
- 验证手机触摸、键盘操作、明暗主题与子路径链接。

## 实现与验证记录

- 阅读组件位于 `src/pages/posts/[...slug]/_components/ReadingNavigation.astro`，交互层位于同目录 `reading-navigation.ts`；课程邻接选择位于 `src/utils/getPostNavigation.ts`。
- 正文容器仍为 768px，包含两侧各 16px 内边距，宽屏实际正文宽度为 736px。课程侧栏在可用宽度 1360px 起常驻，本文目录在 1120px 起常驻；手机宽度正文随窗口自然缩小。
- 保留文章作者已有的正文内嵌目录，但不把其 `Table of contents` 标题收进侧栏章节目录。正文标题锚点增强仅处理正文，不再向抽屉标题注入锚点。
- 课程元数据缺失或为草稿时，课程导航使用课程 slug 作为文本标题，不链接到不存在的课程页；讲义列表和课程内前后讲继续可用。
