首页介绍下方的中式庭院景窗。基于 `pic/清华园-卡通.png` 与 `pic/香香可爱.png` 提取独立图层，以 Three.js 实现分层景深和轻微转动。香香与二校门门楼建筑本体（不含旗杆）的视觉高度接近。猫咪、树木和校门为插画平面；庭院框架与地面为三维几何体，不支持绕到插画背面。

## 布局选择

- 前框：有厚度的粉墙、灰瓦、八角景窗和石台，能够遮挡院内物件。
- 近景：左侧树木，右前方的香香；香香与原来的垫子背景分离，卧在共同的石地上。
- 中景：二校门在左后方，门洞透明，可以看见后面的树木与院墙。
- 远景：三组不同位置的树木，后方院墙与侧墙。
- 地面：独立三维石板和砖缝，配合主体轮廓投影、接触阴影及围墙投影。
- 沿用博客正文宽度，手机保留主体同框；只保留低调的「方寸小院」题名，移除场景外的地点、主体标签和说明句，校门原有匾额保留。

## 视觉与交互

- 透明画布与透明静态图沿用页面背景，适配明暗主题。
- 独立贴图处于不同深度，以轻微相机位移与转向制造视差。Three.js 的 WebGLRenderer 负责渲染，无需另外编写一套 WebGL 应用。
- 场景不自动循环摇摆；移动指针时更新，离开后回正。触摸区域保留纵向滚动。
- 不提供互动开关。系统要求减少动画时静止，触摸结束后回正。
- 无 JavaScript、无 WebGL、纹理失败或上下文丢失时显示同构图静态图；移出视口、切换后台或相机已到达目标后停止绘制，离开首页时释放资源。
- 所有资源由 Astro 处理 GitHub Pages 的 `/fangfangfang` 前缀。

## 文件

- `src/components/GardenScene.astro`：容器、静态图与响应式样式。
- `src/scripts/garden-scene.ts`：图层材质、轮廓投影、相机、交互和资源生命周期。
- `src/scripts/garden-courtyard.ts`：景窗、墙面、瓦檐、铺地与接触阴影。
- `src/assets/garden/`：派生图层与场景渲染静态图。
- `src/pages/index.astro`：首页接入点。
