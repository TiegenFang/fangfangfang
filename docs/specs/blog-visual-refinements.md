## 推荐方向：书斋式博客

这是结合当前页面提出的设计判断，不是参考网站的原样复刻。

1. 统一字体层级。当前首页中文书卷气较强，英文姓名粗等宽字与其反差大；下一步可将姓名调整为协调的衬线字体，等宽字体只用于代码与必要的技术字段。书法仅用于牌匾。
2. 统一色调。浅色模式用非常浅的暖纸白、墨灰正文、低饱和青灰链接，与粉墙灰瓦衔接；深色模式应配套测试文字对比度，不直接反转图片颜色。
3. 收紧首页节奏。将简介、社交链接和景窗作为一个整体，压缩社交链接与瓦檐之间的留白，让文章入口更早进入视野。
4. 改善列表层级。文章标题用墨色并略增字重，日期弱化为小号灰色，摘要保持正常可读对比度；以段间距分组，减少重复分隔线。精选内容可比普通文章更突出，但不必做大面积卡片。
5. 加入课程入口。博客同时承载文章和课程，首页应给课程独立的简短入口；课程名与一句介绍即可，讲义列表继续保留讲次关系。
6. 优先保护长文阅读。检查中文、英文、代码、公式和移动端换行；美化不应造成全文书法字、过宽段落或拥挤的侧栏。

建议先落实字体、色调、留白这三项，确认首页整体气质后再调整课程入口与文章列表。
