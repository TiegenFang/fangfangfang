# 首页与方寸小院调整

2026-10-07：小院、旧互动及首页专用色板已经被 [雨夜街角与首页样式统一](./rainy-convenience-store.md) 取代。本文保留历史决策；独立文章、项目、相册与课程入口的内容布局继续沿用。

日期：2026-10-06。状态：两轮方向与整体方案已确认，页面与交互已实现；浏览器实测及静态封面同步待 Browser 权限校验恢复。

## 目标

首页先让访客认识作者和「方寸之间」，再发现值得阅读的内容。课程保留次要入口，首页整体避免呈现为课程目录。

## 已确认的设计方向

- 首屏以短欢迎语、方寸小院和少量精选建立个人气质。
- 保留香香与二校门，重新组织小院构图、比例、光影和前后层次。保留香香的毛色与神态。
- 香香的互动采用「喂一根猫条」：访客主动触发后给一次短回应，回应留在小院内。
- 首页不逐篇展示课程讲义。课程收进一个简短入口，内容区展示独立文章、项目与相册。
- 首页精选与「随便逛逛」共用精选内容；后续通过现有的精选标记维护。
- 首页采用暖纸白、墨色文字、低饱和青灰的书斋气质，与粉墙灰瓦衔接。本轮范围为首页及小院。

## 用户给定的交互约束

- 小院下方提供明确的「带我随便逛逛」按钮。
- 每次从精选的文章、项目和相册中推荐一个内容，先显示标题与简介，由访客决定是否进入。
- 交互范围控制在一两个元素。香香不追随鼠标，不自动播放猫叫，不在阅读长文时持续弹话。
- 小院入口采用真正可聚焦的按钮或链接，同时支持手机触摸和键盘操作。

## 具体方案

### 首页顺序

1. 短欢迎语、作者介绍与社交入口。
2. 方寸小院：香香与二校门作为视觉主角，提供喂猫条和随便逛逛两个主动互动入口。
3. 「从这里开始」：从共用精选中展示文章、项目、相册各一项。采用各类中最近的内容，无需另维护一份首页清单。
4. 「最近留下的东西」：展示三条近期独立文章、项目或相册，避开上方已展示的内容。用紧凑列表而非完整目录。
5. 简短课程入口，进入课程页浏览全部课程与讲义。

首页的精选与近期内容均不逐篇展示讲义；文章列表、课程页、归档及搜索保留既有的讲义访问方式。

### 小院构图与反馈

- 保留有厚度的景窗、粉墙灰瓦与「方寸小院」牌匾；二校门退到中景，香香安放在近景石地，调整比例与遮挡关系。
- 用石阶、少量绿植和小水碗增加生活感；光影与材质服务于前后层次，场景适配明暗主题。
- 场景保持安静，将主要互动集中到两个入口。取消原有移动指针改变视角的行为，以构图和光影呈现景深。
- 喂猫条入口是香香附近的真实按钮，有可见提示「给香香一根猫条」和明确的焦点轮廓。
- 点击后显示一次短小猫条反馈与一句短回应，例如「猫条收下了，陪我坐一会儿。」动画结束后恢复安静，文字只留在小院的固定回应位置，不采用浮动弹窗。
- 系统要求减少动效时，保留文字回应，省略动画。

### 随便逛逛

- 「带我随便逛逛」是小院下方的真实按钮。
- 点击后在按钮下方展开一张推荐预览，包含内容类别、标题、简短介绍与明确的进入链接。
- 初始不显示推荐；每次主动点击产生一个结果。再次点击同一按钮更换内容，池中内容轮流出现，避免连续重复。
- 更新结果时按钮保留焦点；结果通过温和的辅助技术通知呈现，进入链接按正常顺序可聚焦。进入内容仅发生在访客点击链接之后。
- 文章、项目和相册使用已有站内 URL 工具生成链接，兼容 `/fangfangfang` 子路径。
- 推荐功能与 WebGL 解耦；小院显示静态图时仍可推荐内容。无 JavaScript 时保留静态图与首页精选链接。

### 初始精选内容

两轮讨论中建议的六项作为初始选择；保留项目中已存在的 `interIsoFoamEHD-thermal` 精选标记，推荐池因此共七项。

| 类别 | 内容 |

| 文章 | 你好，方寸之间 |
| 文章 | PINN 变体谱系：一份可核验的深度调研 |
| 项目 | XYZRender Workstation |
| 项目 | PINNs Learning |
| 项目 | interIsoFoamEHD-thermal（已有精选） |

仅使用已发布、非草稿、非讲义的精选内容。标题与简介来自既有内容；简介较长时，为首页写一句忠实的短介绍。首页只加载相册封面，不加载相册全部照片。

## 实施与验收

- 复用现有 Astro、Three.js 与内容集合，不增加应用框架或推荐服务。
- 样式限定在首页与小院；文章阅读页保持本轮范围之外。
- 更新场景后同步静态封面与小院说明文档。
- 检查桌面和手机布局、明暗主题、键盘操作、手机触摸、减少动效、静态图回退，以及退出首页后的资源清理。
- 确认推荐预览没有自动跳转，反复点击不会连续重复，返回首页不会重复注册事件或出现多个结果。
- 代码实施后按仓库约定执行格式化、lint、格式检查和完整 build。

## 验证记录

- 已运行 `npm run format`、`npm run lint`、`npm run format:check` 与完整 `npm run build`。Astro 检查无错误，静态页面与 Pagefind 索引成功生成。
- 基于真实构建 HTML 与交互模块进行了内存 DOM 集成测试：35 次推荐在五轮内分别遍历七项内容，无相邻重复；结果包含标题、简介与站内链接，推荐操作不改变页面地址，焦点保留在按钮。
- 验证了减少动效下的文字回应、正常动效下的有限反馈与重复点击保护、退出后的事件和计时器清理，以及空推荐池、单项池和无效数据的回退。
- 浅色与深色模式的次要文字对比度分别为 5.11:1 与 7.63:1。
- 临时 DOM 测试工具不写入项目依赖清单或锁文件。内存 DOM 测试不等同于手机触摸、真实键盘或 WebGL 的实际浏览器验收。
- Browser 报错：`saved browser permissions could not be verified`。在权限校验恢复前，实际桌面/手机排版、主题切换、WebGL 视觉效果与新静态封面导出尚未完成。
