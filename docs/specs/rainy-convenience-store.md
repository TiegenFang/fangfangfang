# 便利店入口与加载转场

日期：2026-10-07。首页保留原内容布局与全站字体、色板，便利店的位置作为像素入口，完整场景位于独立页面。

## 用户最终要求

“blog现在放便利店的那个页面只是作为一个入口，像素风猫咪开门，然后跳转到那个页面。跳转过程需要是加载动画，像素风格进度条，然后文字是正在进入方寸之间。”

- 首页显示像素便利店门与香香。点击入口后，香香抬爪、门打开，再显示加载动画并进入独立便利店页面。
- 转场与加载期间的可见文案为“正在进入方寸之间”，使用像素进度条和像素猫咪。
- 完整便利店继续使用 `public/scenes/Hoshi Mart — a corner store diorama.html` 原文件，其全部模型、材质、控件与互动保持不变。源文件 SHA-256：`461A946F4953432955354C7390E7BAC0DF9012DE76B8A8AF417490C54A0BDC51`。

## 实现位置

- `src/components/CornerEntrance.astro`：首页像素插画与真实入口链接；未点击时不运行 Three.js 或加载完整场景。原 iframe 组件删除。
- `src/components/PixelCat.astro`：可缩放的像素香香，入口和加载动画共用。插画与店招字形由 SVG 绘制，不增加图片或字体依赖。
- `src/components/CornerLoader.astro`：全屏加载动画、像素进度条、准确文案和失败重试。
- `src/scripts/corner-entry.ts`：点击开门、延迟跳转、加载阶段、场景初始化等待、页面返回与监听清理。
- `src/pages/corner.astro`：全屏独立便利店页面，在 iframe 内加载用户 HTML，保留原文件的独立样式和互动。
- 首页入口为 `/fangfangfang/corner/`；场景文件名经过 URL 编码，并带 `/fangfangfang` 前缀。

## 交互与加载

- 整个入口使用原生链接，支持触摸与键盘 Enter。新标签页的修饰键点击保留原生行为；禁用入口脚本时仍可直接跳转。
- 普通点击先开门，随后出现全屏加载动画，再导航到独立页面；重复点击只触发一次跳转。离开或返回首页会清理待执行跳转并恢复入口状态。
- 独立页面按打开文档、文档加载、场景初始化与绘制时机推进进度条。通过原文件已有的 `window.__hoshi.ctx` 读取初始化状态，等待两个动画帧后完成加载；不修改或注入原文件脚本。
- 进度条表达加载阶段，不宣称是网络字节下载百分比。完成时先填满，再淡出显示便利店。
- 超过 25 秒仍未初始化时显示重试。重试必须等新 iframe 文档加载，避免将旧文档误判为已就绪。
- 减少动效模式省去开门与行走动画，保留加载状态和手动进入。页面切换和页面缓存返回时处理定时器、帧回调与监听生命周期。
- 加载屏显示期间阻止场景控件接收焦点，加载完成后恢复原控件操作。
- 博客继续使用内页的 `Layout`、`font-app` 和全站色板。场景与加载屏的夜色仅用于这一入口和独立场景。
