# 0001 — 课程用独立内容集合 + 讲义归属建模

日期：2026-09-02
状态：已采纳

## 背景

站点需要承载「课程」内容。astro-paper 模板只有一种内容类型（posts）。可选方案：

- **A. 标签/分类**：课程只是打了标签的普通文章。零开发，但没有"一门课"的整体视图。
- **B. 独立课程集合 + 轻量归属**：新增 `courses` 内容集合（课程详情页），讲义仍是 posts，通过 frontmatter `course` 字段归属，`order` 字段排讲次。
- **C. 完整课程系统**：课程含进度、课时编号、视频外链、练习等结构化字段。

## 决策

采用 **B**。

## 理由

- 博主的核心诉求是"记录课程 + 有整体感"，B 用最小代价满足；A 做不到整体感，C 的结构化字段短期用不上，且一旦内容写进去，迁移成本随内容量增长。
- 讲义保持为普通 posts，复用模板全部既有能力（RSS、搜索、归档、标签、分页、相邻文章导航），无需为课程单独重建一套浏览基础设施。
- B → C 是增量演化：将来需要进度/课时结构时，可以给 courses schema 加字段而不推翻现有内容。

## 后果

- 课程不进入 posts 时间线对应的任何列表之外的独立 RSS（课程本身只有详情页，无订阅源）。
- 讲义的 `course` 字段是约定俗成的软引用（slug 字符串），课程改名 slug 时需要同步修改讲义 frontmatter——接受这一手工成本，因为课程数量少且改名罕见。
