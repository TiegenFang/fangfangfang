你现在看到的这个站点，本身就是一个持续演进的项目。技术上它是 Astro 7 + Tailwind CSS 4 的纯静态站点：内容用 Astro Content Collections 管理（课程、讲义、项目、影像），搜索靠 Pagefind，公式靠 KaTeX，首页的「方寸小院」景窗用 Three.js 做分层景深，部署在 GitHub Pages 的 `/fangfangfang` 子路径下。

设计上它有自己的坚持：克制的动效、书卷气的排版、明暗两套主题都过得去。站点的架构决策记录在仓库的 `docs/adr/` 里。
