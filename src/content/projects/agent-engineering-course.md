当 AI 编码助手变成日常工具，「会用」和「用得好」之间差着一门课。这个仓库是一套成体系的中文 Agent 工程课程：起步章在浏览器里零安装完成（W1–W4，BYO-key 直连实验），模块 0–12 进阶线覆盖从 Codex、Claude Code 到 Memory、Skills、MCP 与 API 实战。

仓库同时承载 Astro/Starlight 课程站、贯穿课程的设备遥测练习（labs）、本地课程检查器（checker，匿名结果契约）与规划文档。课程站已发布 v3.0.0：[在线阅读](https://tiegenfang.github.io/agent-engineering-course/)。
